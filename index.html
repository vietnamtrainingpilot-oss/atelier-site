Eight domains, one interface.

Routers are named for the job, never for the tool — so the underlying skills can change without renaming anything.

web-design

The largest domain: landing pages, portfolios, redesigns, design systems, UI, and scroll or cinematic motion. Forty-six skills, because design taste is not one decision — it is a dozen, and only one of them should lead any given page.

46 skills

video-production

HTML-to-video, React video, social promo. The workflow is picked from your input — a PR, a product URL, an audio file — not from the format you want out.

25 skills
